How this tool works

An internal tool for the LFMP team. You fill it in for the client, usually on a call. It asks every question on Onboarding Form v3, in the same order and with the same wording, split into 4 steps.

Today (preview)

WhatHow it works now
SavingAnswers are saved in this browser on this computer. Another computer won't see them.
GHLNot connected. Nothing is written to contacts, and no tags or reminders are created.
Export (admin mode)Turn on Admin mode, then click Export beside a client on the client list: PDF (the full submission, formatted for sharing or printing; password entries are masked), CSV or JSON. The admin bar also has All clients (CSV).
Password fieldsShown as they are on the original form. They're marked 🔒 in field-mapping view for a later review.
CompletionA page is complete only when every visible required question is answered and, if the page has an access status, it's Granted or Not Applicable. Pending stays open.

Next phase (proposed, not built)

RELAYA small Cloudflare Worker holds a contacts-only GHL token. It searches the client's contact, loads saved answers and saves each step by field key, so no manual mapping is needed. It also adds the tag onb-stepN-done.
LOGINOptional later: Cloudflare Access, so only @lawfirmmarketingpros.com staff can open the tool.
